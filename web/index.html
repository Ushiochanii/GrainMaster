Canvas

Scroll to zoom. Drag to pan. Click a dish or seed to inspect it. Esc returns to the photograph.

Mask colours

Red: Low Confidence. Brown: High Confidence. Grey: excluded. A white outline marks your selection. These categories combine automatic quality flags and accepted corrections; they are not calibrated probabilities or measured seed colours.

Review

C accepts an instance. X excludes it. N / P select the next / previous seed. Restore returns to the automatic assessment. Review changes inclusion, not the mask.

Importing a photograph does not start analysis. The review filter changes the list, while the canvas retains surrounding instances.
